# 原图模糊、梯度双边与直段结束检测：S1

本核心只接收原始 BGR 图和已冻结 E1 两点。E1 首点在远端，末点朝卷面；两点是人工/旧算法提供的条件，不计为本轮新增检出。输出仅限同方向的**光学直线段**，不判断是否为同一根材料、入卷接触或 t0/t1/t2。

1. 原图用 `sigma=2.4 px` 高斯模糊，抑制绳股小纹理；灰度 Sobel `ksize=3, scale=1/8` 求 x/y 梯度，保存全分辨率梯度模长。灰度 0 仍是有效像素。
2. 在 E1 内 9 个横截面测左右外沿：两侧必须分别存在反向的法向梯度，且绳体相对左右背景都具备对比度。亮绳、暗绳均评估；候选光学宽度 10–45 px。少于 4 个可信截面则拒识。仅根据可信外沿将 E1 方向微调至多 2.5°。
3. 从 E1 末点向卷面每 4 px 测一个横截面，在入口宽度的 0.85–1.15 倍和轴线 ±0.3 根宽内找双边。必须同时通过绝对及相对入口的梯度和双侧对比度门槛；5 步窗口过滤孤立噪声。明暗极性允许逐段变化。
4. 仅用前 500 px 已通过双边门槛的连续证据稳健重估一次直轴，约束角增量不超过 2°；重测后若该前段支持率下降超过 0.10，则保留原轴。后段长度不参与轴线选择。
5. 连续失去双边支持超过 48 px 时，结束在**最后一个实际得到支持**的截面。短缺口允许继续搜索，但不补画成可见绳；输出 `supported_segments_xy` 供逐段叠加。抵达原图边框或 5000 px 搜索预算是独立停因，不能称为发现真实绳端。

接口：`analyze(image_bgr, seed_xy, config) -> (fields, prediction)`。`fields` 含同原图尺寸 `blurred_bgr` (`uint8`) 和 `gradient_magnitude` (`float32`)；`prediction` 为可 JSON 序列化记录，含状态、停因、E1、宽度、仅新增支持点、分段点、末端及逐步梯度/对比度/支持判定。`points_xy` 的首点是 E1 末点，其余为算法确认点；入口本身不计检出。若 E1 或其双边无效，`status=UNKNOWN`、`points_xy=[]`。

这是传统图像证据的离线实验核心。梯度消失可能是遮挡、阴影、失焦、反光或局部弯曲，不自动等于钢丝绳真实直段结束。邻近卷绳/工具也可能具有双边；要以冻结开放开发图及独立人工复核判断效果，不能把 292 图运行成功数当准确率。
