# 全卷面钢丝绳边界基准 F3（RB-F3.0.0）

2026-10-28，按用户本轮明确要求，把已完成的“全卷面协同 F3”登记为后续钢丝绳边界研究基准，版本号保持 **RB-F3.0.0**。这是用户对结果的质性认可，没有逐根或逐像素真值准确率，也没有因此验证材料身份、活动绳接触点或设备控制能力。

正式来源：[F3 all_001](../../../数据资产/05_派生与实验结果/camera_condition_full_surface_joint_20261028_v3/all_001)。固定400张开放开发图片，左右各200张，全部处理完成。源目录及C3、D4、F1、F2旧基准保持原样；本次归档不重跑任何检测、拟合或模型。

## 基准包含什么

F3在既有完整卷面掩码S内连续归一化，运行原D4宽沟提取、黄点检测、归类和局部曲线拟合，以便利用比旧过渡带更长的图像上下文。融合时保留原F2边界，在旧过渡带T内加入通过图像支持、未知遮挡、强绳体及相邻间距检查的新片段；允许有单侧参考或有充分图像证据的独立片段，不再把旧C3与旧D4两端都存在作为显示新片段的必要条件。新黄点仍来自实际检测，不由拟合曲线制造。

输出分成“D4全卷面候选”和“F3融合边界”两组。候选图包含尚未进入最终结果的点，不能把候选点数当已识别边界数。F3正式边界保留F2原有几何和T外显示，因此旧ROI缺失、既有曲率问题和不满足新增条件的空白仍可能存在。

- `snapshot/source_snapshot/` 保存正式全量运行的43份源码与协议快照，包括本版5项和38项上游谱系文件；逐一核对当前源文件与运行快照哈希。

- `snapshot/config/image_manifest.csv` 是原400图清单。`dependency_manifest.json` 锁定400张原图、每图23项固定输入依赖及5200项预测输出；按明确规范路径去重核验字节哈希，拒绝跟随junction或其他重解析点。图片和大型逐图预测继续留在原址，不重复复制。

## 已有证据及限制

正式运行400/400完成、0处理异常，独立结构与保存结果审计400/400通过。43份冻结来源保持一致。399张有新增，1张无新增保留在分母；4,272,920个全卷面D4候选点、50,894条候选曲线、156,191个接受新增点和691,092个新增像素仅描述产物数量。

固定图实看显示，部分F2原空白接缝出现了新的绳纹片段；L_run f648预选框新增974像素，其中915像素距旧F2边界超过0.3倍绳距；ruler_left05预选框新增530像素，其中413像素超过该距离。这些是固定框覆盖变化，不是真值准确率。已保存的端区修正和固定12图与全400逐字节一致性证据可回溯。

仍存在SAM掩码遗漏、极暗或反光区域漏检、孤立短段、局部归类/拟合偏差，以及继承的F2局部拱起。真实活动绳遮挡不能通过强行补点“解决”。拒识不自动等于正确，平滑或等间距曲线不证明同一根材料、真实三维接触或t0/t1/t2。用户本次认可允许后续研究以该版为比较基准，并非工业控制验收。
