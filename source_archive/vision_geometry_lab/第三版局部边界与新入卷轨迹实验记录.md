# V3：局部边界与新入卷绳表面轨迹实验

日期：2026-09-26。范围：独立离线实验 `vision_geometry_lab`。未接相机、灯光或运动设备，未修改原实时监控/控制系统。

## 结论先行

1. 用户关于右侧错误白点的怀疑部分成立：局部绳股受黄色反射影响，及卷面近竖直侧轮廓，会混入交界候选。但即使去掉坏点，一小段正确左弧也不必然足以稳定确定整条椭圆。
2. V3 分开“可直接测得的局部边界”与“完整椭圆模型”。完整椭圆不稳定时仍保留有支持的绿色边界，不强行补齐遮挡区。
3. 用户六个红点证明：旧自动轨迹候选追到了相邻亮绳纹，没有沿所指新入卷路径延续到暗处。此问题不是简单显示错误。
4. 加入人工提示后，局部对比度、亮暗双向特征和受限路径搜索能够接近该路线，但仍不能可靠区分整根绳中心、绳体边缘与绳股纹理。**本次完成的是候选追踪诊断，不是全自动新入卷绳识别验收。**
5. “沿绳体真实弯曲路径判断贴边”比把自由绳无限延长成直线更贴近物理过程；是否更精确仍需实验证明。本次不输出最后一圈、新层或施力事件。

## 边界失败原因及修改

原有处理将像素候选交给完整椭圆模型；模型在删去一段支持后变化较大，就不绘制绿色线。这一质量保护不宜简单放松，但其显示和任务分工需要改变。

本版增加二维法兰颜色邻域支持检查，拒绝缺乏实体黄色邻域的弱反射过渡及含义不明的侧轮廓段；保留原始点供白点图层复核。局部拟合不跨缺口、绳屏蔽带或缺失支持。完整椭圆仍单独做几何退化、正交残差、删段敏感性检查。

25.1 s 能看到有效左侧局部曲线，但完整椭圆仍被拒绝，这不是程序没有画出来，而是没有足够稳定的全局模型证据。26.5 s 则仍能得到通过检查的椭圆。

局部绿色边界不是圆锥曲线真值，其精度仍受黄色包覆起伏、反光、镜头畸变及颜色条件影响。不同颜色法兰目前也不保证可用。

## 新入卷轨迹算法与局限

自由绳直线及其观测段提供入卷方向。在定向条带内提取脊线候选，使用多路径搜索约束连续性和弯曲度。全自动分支保留亮脊候选作为对照；人工提示分支增加局部对比度归一化、亮暗双向极值，并沿用户路线限制搜索。

邻近法兰弧不参与路径得分，不把候选强制吸到弧线上后再宣布贴边。边界仅辅助搜索方向及事后几何比较。重复纹理、多路径、过曝、证据缺口或中心/实体边未区分时，结果明确保持 `identity_ambiguous`。

更专业的名称建议为“新入卷绳表面轨迹”。它包含卷绕的螺旋分量，透视下不必是严格椭圆。评价贴边时应研究：新入卷绳靠法兰一侧的实体边缘，与法兰内侧局部边界是否在同一接触区域接近；不要求整条中心线与法兰曲线重合。局部光学宽度尚不等同物理绳径，投影相交也不证明真实三维接触。

## 软件使用

1. 关闭旧实验窗口，重新双击 `启动独立弧线与活动绳实验.cmd`。
2. 打开上述原始视频，跳到 24.6 s / 第 247 帧。
3. 点击“导入本帧轨迹提示”，选择 `outputs/wound_curve_v3/manual_247/reference.json`。像素指纹不匹配会拒绝，不会误套在其他帧。
4. 观察紫色候选，Ctrl+滚轮放大、右键拖动、F2 切换标注。界面明确标为人工提示；换帧提示清除。
5. 关闭“新入卷轨迹候选”可单独观察边界。完整椭圆默认关闭，勾选后以淡蓝虚线显示；失败不影响局部绿色边界。
6. 保存时 `display.png` 表示当前开关和提示的全图，`overlay.png` 为统一简洁叠加，`diagnostics.png` 为统一诊断叠加，`source.png` 为干净原图；JSON 记录人工指导来源和显示开关。任何参数/提示变化都会清除旧结果，重新检测后才能保存。

## 下一阶段的可检验目标

1. 先用本次六点路线复核：暗处的像素特征是整根绳中心、实体边，还是绳股纹理；不能把股丝脊线当成绳中心。现有标注已足以推进这一诊断，暂不要求再批量标注。
2. 若该路线确认正确，再研究从可靠自由绳自动进入同一根绳的连续路径，以邻帧外观和局部形状验证身份，保留多个假设；不依靠“离法兰最近”选中目标，也不把每帧人工提示作为自动方案。
3. 在 246～248 及更早/更晚帧上，使用同一定义测量法兰侧绳体边缘的局部间隙；只在两侧都有可信证据时输出可见贴边候选时间区间。被绳遮住的弧只能报告模型推断及不确定性。
4. 同时检查其他时段、另一相机和人工遮挡段的误候选；完成该项前，不升级为最后一圈事件，更不用于自动施力。
