# V2：活动绳屏蔽、统一椭圆弧与交点实验

日期：2026-09-26。范围：仅 `vision_geometry_lab` 离线实验；未改原实时检测、根数、换层、设备控制算法，未连接硬件。

## 结论先行

本版落实了用户提出的屏蔽条带和平滑圆锥曲线方案，改进了近边时的自由绳中心线、光学宽度检测，增加解析交点和不确定性诊断。

**截图26.5秒的误边界已得到针对性处理，但不能据此宣布“上一层最后一圈开始时间”检测成功。** 连续视频中仍存在几何证据不足和拟合变化较大的帧。这不是通过画一条平滑线就能消除的问题；本版没有隐藏这些失败，也没有强行降低门槛让视频在人工给定时间触发。

## 1. 截图复现与原因

截图路径中的 `现场视频/右侧相机（拍摄左边缘）/left_DA9627065.avi`，与正式同步记录 `现场视频/训练采集/双相机同步/dual_20260924_111500/left_DA9627065.avi` 为同一文件（SHA256一致）。因此这里按正式同步记录左相机、拍摄右边缘分析，文件夹名称不作为算法输入。

复现帧：10 fps，0起算第265帧，即26.5秒。程序显示为第266帧。

发现三个具体原因：

1. 原来的颜色过渡边界搜索没有屏蔽活动绳。绳遮在黄色背景上也构成明显颜色过渡，部分绳像素因此被选进边界。
2. 原显示是局部边界片段，没有统一几何模型；像素噪声、纹理与局部小缺口形成分散曲线。
3. 原绳宽测量依赖反光亮带。编织纹理让亮带宽度沿绳明显变化，宽度稳定性检查会拒绝输出。另有绘图问题：宽度未知时零偏移黄线会覆盖橙色中心线。本版已修复。

## 2. 本版实现

### 2.1 先检测绳，再屏蔽边界测量

活动绳检测不依赖拟合弧线。以当前帧中心线及延长线为中心，屏蔽半宽取：

`光学宽度观测上界 / 2 + 额外余量（默认8 px）+ 3 × 直线法向敏感度`

这里的系数是保守工程设置，不是统计3σ保证。没有宽度时仅允许诊断性宽度代理参与“排除像素”，不能把代理当成真实绳径。无可靠绳线时不沿用旧帧屏蔽带。

完整黄色区域仍用于粗定位；精测剖面不会使用屏蔽带内像素。不会通过把图片涂黑来产生人工边界。必要时在带外重新搜索有真实颜色过渡的安全剖面。

### 2.2 单一椭圆模型

归一化直接椭圆拟合提供初值，分布均衡的鲁棒候选选择排除离群点，再用到椭圆的正交距离精修。只使用带外实测点，不让“应该相切”反过来牵引绳线或弧线。

- 绿色实线：拟合模型附近有实测支持。
- 绿色虚线：同一模型在观测跨度内补全缺口，尤其是绳屏蔽区。
- 白点：可选显示的原始边界候选。
- 不绘制从未被观测跨度约束的整个底部半椭圆。

通过删去不同角度块后重新拟合，观察模型变化。短弧、退化形状、严重变化、非椭圆一致的边界会拒绝。可绘制但不确定性较大时显示 `uncertain_model`，仍可禁止相切判断。空角度块属于无数据，不当作拟合失败；该计数问题已增加回归测试。

模型残差不是实际定位精度；拟合模型只能降低随机散乱，不能消除错选边界、真实轮廓偏离椭圆和镜头畸变等系统误差。

### 2.3 近边绳线与光学宽度

优先测量远离卷面的清晰自由绳段。两侧有黄色背景时，利用黄色与消色差钢丝绳之间的差异提取轮廓；证据不足时才用原孤立亮条方法。精修限制在已观测的自由段，避免卷面纹理拉偏直线。

同时输出参考位置、代表光学宽度、观测变化范围、角度和法向敏感性。不把光学范围称为实体绳径或统计置信区间。黄色平行线只在观测段画实线；延伸到接触区时为虚线。

### 2.4 两交点接近的判断

正确术语是“交点”。直线与完整非退化椭圆有2/1/0个实交点；与部分可见弧只有1个交点，不等于与整个椭圆相切。

本版同时计算完整椭圆交点数、当前弧内交点数、弦长、法向间隙、绳带两侧的几何关系。交点接近阈值由当地曲率和有上限的像素诊断容差换算，不使用固定5px或10px弦长：曲线越平缓，同样很小的法向误差也可能产生很长的弦。

容差考虑候选附近的模型敏感性、直线残差，以及从自由绳参考点传播至候选位置的角误差。光学绳边还需考虑宽度变化；不能把自由段代表宽度直接当作接触处已测宽度。误差预算超限时输出“不确定”，不因为误差大就放宽成“已到边”。

所有结果保持：

`last_turn_confirmed=false; physical_contact_confirmed=false; new_layer_confirmed=false; force_command=null`

## 3. 26.5秒定量复现

以下均为原始4096×3000像素坐标，没有缩放到UI显示尺寸：

| 项目 | 结果 | 解释 |
|---|---:|---|
| 活动绳角度 | 12.733° | 图像无向直线角度，不是移动方向 |
| 光学代表宽度 | 20.90 px | 自由段测量，不是标定实体直径 |
| 光学宽度观测范围 | 16.35～24.28 px | 沿绳变化；不保证接触处也在此区间 |
| 绳线拟合残差 | 0.415 px | 与所选支持点一致性，不是真实精度 |
| 屏蔽带半宽 | 22.23 px | 宽度上界、余量与法向敏感度共同决定 |
| 不屏蔽时带内边界候选 | 215点 | 同版检测器的消融对比，不是V1全部错误点统计 |
| 屏蔽后带内边界候选 | 0点 | 验证带内像素不参与精测 |
| 屏蔽后边界候选总数 | 519点 | 不等于519个独立、准确真值 |
| 椭圆正交拟合残差 | 1.158 px | 模型内点残差 |
| 留块模型敏感度 | 5.520 px | 非标定误差界限 |
| 中心线与拟合椭圆交点 | 2个 | 两个均位于建模弧段内 |
| 交点弦长 | 457.9 px | 不是两个真实物理接触点的距离 |

因此此帧可以画出更连贯的边界与绳线，但输出仍应是“模型/绳线不确定性过大，不能判近切”。光学绳边到模型的间隙与中心线不同，不能仅拿中心线交点数宣布物理贴边。

## 4. 回归与事件时序检查

最终统计以 `outputs/regression_v2/summary.json` 和 `outputs/tangency_v2/summary.json` 为准。素材均为已用于开发或查看过的历史素材，是回归检查，不是独立盲测；人工时刻只在结果汇总中对照，未输入检测器。

本版检查69帧：42张现有标注图、2张现场BMP、25张两段换向录像关键帧。另外以0.5秒间隔补入人工关键时刻，检查两段录像共50帧时序。

最终统计：

- 69帧均取得部分边缘候选；43帧椭圆通过可绘制门槛。其余23帧因留块变化过大拒绝、2帧与椭圆形状不一致、1帧短弧不足。**不是43帧已达到真实精度验收。**
- 21张标注活动绳可见的图中检出18张；20张标注画外的图均未误报，1张标注不确定的图也未强行输出。3张保守漏检仍保留，并未宣称全场景成功；已有SAM2候选掩膜的20个样本均能重新测得绳线。
- 50帧时序检查：17帧有可绘制椭圆，但只有14帧几何关系落在可用弧域，其中13帧不确定性过大，另1帧只是割线。**没有一帧满足本版有质量约束的近切候选条件，因此“交点合并可稳定定位最后一圈”的假设本轮尚未验证通过。**
- 顺序执行回归时，69帧CPU总测量中位耗时约1.20秒、P95约1.35秒；不含SAM2辅助耗时。此版是离线精测实验，尚非实时部署版本。
- 65项代码测试全部通过，覆盖屏蔽、圆锥拟合、求交、误差传播、绘图、UI结果有效性及保存提交/失败处理；真实Tk隐藏窗口完成了视频解码、26.5秒跳转、工作线程、显示和参数失效检查；CMD启动冒烟测试通过。

人工时间参考：

| 录像 | 上层最后一圈开始 | 新层开始 | 新层首圈完成 |
|---|---:|---:|---:|
| 111500，无敲击的右边缘换向 | 24.3 s | 27.3 s | 30.0 s |
| 111143，存在遮挡/敲击 | 11.4 s | 14.4 s | 16.8 s |

不能把本版“拟合可用率”当作计量准确率，也不能把某个近切候选当作最后一圈或新层已确认。尤其24.3秒的轮廓在移除少量支持后变化很大，27.3秒虽能拟合但不确定性仍高，30.0秒也未取得足够稳定模型。因此本实验尚未通过上述三个事件的时间验收。

## 5. 如何复核、下一步做什么

1. 关闭旧实验窗口，重新双击本目录 `启动独立弧线与活动绳实验.cmd`，标题应含“V2”。
2. 打开原视频，跳到26.5秒。先看简洁结果，再开启“原始边界点”“绳屏蔽带”，用Ctrl+滚轮放大、右键拖动、F2对比原图。
3. 检查绿色虚线是否被清楚区分、白点是否避开绳带、黄色虚线是否只被理解为外推。保存结果会保留原图和所有诊断信息。
4. 再看24.3、27.3、30.0秒；不能因其中一帧更漂亮就认为时刻已准。优先检查两侧远离绳带的真实边缘是否足够，而不是为了触发候选扩大诊断容差。
5. 下一阶段先用少量清晰帧对“真实内边界”和自由绳方向做独立像素复核，量化系统偏差；再测试小幅亮度变化、尺度变化及遮挡扰动。只有像素几何误差可控，才研究持续近切、换层和转动相位之间的时序关系。

本轮不要求新增大批训练标注，也没有训练一个新深度模型。SAM2仍可提供本帧候选区域，精测回到原始像素；这比把更复杂模型直接当高精度真值更容易审计。

## 方法依据

- [OpenCV形状拟合资料](https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html)：椭圆/直线拟合的基础。本版归一化稳健拟合、排除带、敏感性检查自行实现，并非直接调用后就宣称精度。
- [OpenCV相机模型与畸变资料](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)：理想投影模型与真实镜头畸变需要区分。本版未实施镜头去畸变和毫米标定。
