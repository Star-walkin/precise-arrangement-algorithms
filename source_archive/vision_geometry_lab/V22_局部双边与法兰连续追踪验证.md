## 实验一：允许多条边同时存在

### 实现

脚本：[v22_local_edges.py](D:/precise_arrangement/vision_geometry_lab/v22_local_edges.py)。

使用红框覆盖的24条原始采样行（索引66～89），每条沿法向取正负65像素。现有上游剖面沿切向平均7像素，因此本轮不是完整二维绳体分割，也没有重新获取颜色信息。

- 对剖面做固定小尺度高斯平滑和中央差分，分别保存正、负梯度峰；不强制只留最强的一条边。
- 保留相邻异号边对；本轮分析宽度为3～40参考图像像素，范围外另行计数，不宣称没有绳。
- 对比条带内部与两侧亮度，分别标记亮带、暗带及对比不足。条带不是新绳身份。
- 同极性峰只与过去的唯一互近邻关联；不跨不可用帧插值。持续条件为至少5个直接观测且跨度至少0.4秒，同时记录首次观测和实际首次可确认时刻。
- 前5秒用于上游参考建立，至5.0秒均不作在线输出；配准或剖面支持失败保持未知。本轮未实现遮挡或材料身份识别，手、工具产生的正常梯度也可能通过。亮度恒定的旧绳、周期纹理也可能满足持续条件。

全片共有14,424个“采样行×帧”单元，其中13,128个可分析。10,487个单元存在多个边缘，9,004个存在分析范围内异号边对，5,555个存在对比达标条带。这些是候选数量，不是正确率。

### 发现并纠正的统计问题

原始边对ID包含对比达标布尔值。复核发现，同一对边的位置和各自ID都连续时，仅因对比值跨过门槛，边对ID也会重新生成。这样会把成像质量波动错误地算成几何跟踪中断。

新增[v22_pair_continuity_audit.py](D:/precise_arrangement/vision_geometry_lab/v22_pair_continuity_audit.py)，只读取冻结的原边对表，不重新找峰、不改变阈值：

- 同一采样行、同一对边ID、同一极性，且原视频帧严格相邻，才连接几何边对。
- 对比是否达标单独统计，亮度变化不再重置几何身份；对比不达标仍会结束“连续对比达标段”。
- 缺帧、边ID变化、极性变化仍断开，不补线。

| 全片统计 | 原V22统计 | 分离后统计 |
|---|---:|---:|
| 满足持续条件的边对链 | 111 | 366 |
| 最长几何边对链 | 0.9秒 | 1.2秒 |
| 持续且对比一直达标的条带段 | 23 | 23 |
| 最长对比达标连续段 | 0.6秒 | 0.6秒 |

纠正后最长边对位于原始行85、30.7～31.9秒，共13帧，首次满足持续条件为31.1秒。其间对比资格翻转8次，边间距8.57～11.05像素。**30.7秒不是新层开始预测。**

在同一原始行、同一对边ID仍连续存在的情况下，3,979次额外的旧边对ID重置全部发生在对比资格翻转处；866个原短片段在分离后所属的边对链达到了持续条件。这不是全片所有追踪重置的统计：边ID变化、缺帧或新边出现等仍会启动新链，剩余短链仍大量存在。对比耦合不能解释全部不稳定。纠正结果见[连续性审计](D:/precise_arrangement/vision_geometry_lab/outputs/v22_pair_continuity_audit/left/report.json)。

这是发现问题后的统计定义修正，不是独立盲测。峰位置没有变，不能宣称定位更准或已正确认出新绳。原V22结果完整保留，后续研究以分离后的统计解释连续性。

### 尚未解决

法向的一维明暗带可能来自绳股、相邻绳沟、反光或包覆物。没有二维连接、遮挡关系和同一根新绳的身份确认，不能将某个边对命名为“旧层/新层双轮廓”。最长链短也不能证明物理上没有凸起；只能说明本轮观测及关联规则未能可靠追踪它。

## 实验二：法兰自然纹理连续追踪

脚本：[v22_flange_tracks.py](D:/precise_arrangement/vision_geometry_lab/v22_flange_tracks.py)。

沿用V20根据首帧选定的每侧两块法兰内部ROI。图像缩至2048宽，在黄色、非极暗/过曝区域选角点；背景另设对照。使用金字塔LK光流、前后向一致性和RANSAC单应模型，检查每块区域的内点数量、空间覆盖、重投影误差及模型退化。失败即重置，不把重新找出的角点冒充同一块材料连续转了一圈。

固定主要门槛：前后向误差≤1分析像素，总内点≥16，每ROI内点≥4，各ROI内点凸包覆盖≥15%，内点比例≥0.7。所有规则与源码在完整回放前冻结，没有按结果重新调整。

| 完整回放结果 | 左片 | 右片 |
|---|---:|---:|
| 合格相邻帧图像变换 / 全部相邻帧对 | 0 / 600 | 0 / 600 |
| 每帧起始法兰角点数 | 200 | 200 |
| 联合筛选后对应点数中位数 | 13 | 7 |
| RANSAC内点数中位数 | 6 | 4 |
| 两ROI中较弱一侧覆盖率的全片最大值 | 2.08% | 4.10% |
| 背景位移中位数（分析像素） | 0.25 | 0.26 |
| 算法处理耗时中位数 | 38.1 ms | 38.5 ms |
| 含解码、像素哈希的串行耗时中位数 | 101.5 ms | 91.1 ms |

耗时是本机离线单路实测，不是双机端到端实时延迟承诺。此次问题首先是对应关系不可靠，而不是算力不足。

进一步检查排除了一个实现疑点：首帧角点在各ROI的覆盖为左84.28%/62.63%、右59.79%/82.58%；垂直跨度分别60/61、47/42分析像素。同点恒等变换可通过所有几何门槛。覆盖分母和点坐标均在2048宽坐标系，未混用原图面积。故门槛并非由ROI大小导致先天不可达。

原完整回放日志没有把“前后向误差失败”和“移出固定ROI”等各阶段损失分别拆开。因此本轮另做一次有界归因诊断，而不是把此问题留到下一次调参。

### 为什么即使拟合成功也不直接输出转角

理想刚性平面旋转的图像变换与平面运动存在共轭关系，这是分析投影变换谱的数学依据；但前提必须先成立。可参阅[Yang等的平面投影与对称性论文](https://people.eecs.berkeley.edu/~yima/psfile/ma-CVIU04.pdf)。本项目黄色包覆物不保证是严格刚性平面。

本轮合成反例中，非刚体剪切也能产生模长近似相等的共轭复特征值，并拟合出接近零残差。因此“看起来像旋转的谱角”并不足以确认机械角度；还需要同材料的多帧刚性一致性、固定轴约束及整圈闭环检验。光流的亮度一致性假设及局限见[OpenCV官方说明](https://docs.opencv.org/4.13.0/d4/dee/tutorial_optical_flow.html)。

所有结果强制标记机械角度不可用、未累计相位、未确认新层、无设备动作。本轮没有生成转速或施力倒计时。

## 对三个时间节点的影响

| 目标 | 本轮状态 | 尚缺证据 |
|---|---|---|
| t0：上一层最后一圈开始 | 未确认 | 同一根新入卷绳贴边的实体证据及其与最后一圈起始相位的关系 |
| t1：新层开始 | 未确认 | 可复核的新绳爬层证据；不能将首次可见侧缘凸起直接等同接触处起点 |
| t2：新层第一圈结束 | 未确认 | 可靠t1和从t1开始累计360°的观测 |

不能将“贴边时间＋固定两圈秒数”写成已经验证的规律。速度变化时需要累计角度；若凸起是在绕到侧缘后才可见，还存在观察相位延迟。当前没有新的事件真值，不能诚实给出三节点误差或准确率。

## 下一步及停止条件

接下来不重复扫描本轮阈值、不扩大模型训练集，先解决两个具体问题：

1. **局部二维实体确认。** 回到未增强、未叠加的原分辨率视频，在红框邻域保留二维颜色与空间连接，检查候选边对是否能连续接回同一根新绳，并与邻近旧层同时区分。优先复核“最后一帧尚不能确认凸起”至“第一帧可确认凸起”的区间，不要求猜一个精确秒数；若肉眼也不能确认就保持未知。此前27.3秒不作为训练正例。
2. **针对跨帧对应做最小对照。** 本轮已经分解了筛选损失，下一步应检验具备更大搜索范围和独特性检验的特征匹配，是否能恢复双区域材料对应，再决定是否采用随动ROI。不能先把前后向误差或15%覆盖门槛放宽来制造角度。仍需固定规则、保留不确定匹配、验证往返与多帧一致性；如果始终无法得到一致材料对应，就停止将该黄色局部纹理用作相位来源。

只有二维新绳身份与连续转角分别有证据，才进行事件时间验收；验收还需不同工况的独立视频。若当前画面缺少必要信息，应明确提出针对性的成像改动，而不是继续叠加滤波和计时补丁。本轮不要求重新批量标注，不要求购买编码器，也不修改现场设备。
