# V10：先验证可学性，再比较传统脊线与路径连接

日期：2026-09-27。所有工作仅离线进行，不替换实时程序，不访问或控制现场设备。

## 先回答：V9效果是否很差？

是。V9两组在8张来源隔离的开发评估图上都未输出有效连续路径，高分辨率组连训练图也没有拟合好。它没有达到当前目标，更不能用于判断新层首圈结束。本轮不以换模型名称、画出大量线条或降低显示门槛来代替目标验证。

## 本轮的两条路线

1. **训练健全性**：只用已经标过的f246训练图，固定输入、九窗和解码器，对照普通BCE与正负平衡BCE＋Dice，均训练1200步。不读留出图，不挑最好checkpoint。
2. **无需训练的对照**：已有V3光度特征、局部归一化单尺度Hessian、Steger式多尺度高斯导数＋Taylor峰点、Frangi式多尺度响应，使用统一自由段锚定与路径连接器，在同18张图、同5像素路径规则上比较。所有方法均输出候选，不自动认定目标身份。

两条路线解决不同问题。单张训练图拟合成功不证明泛化；全部绳纹提取成功也不证明找到了新入卷的那根绳。

## 对用户提供建议的核验

| 建议 | 本项目的采用方式或限制 |
|---|---|
| Steger | 值得测试。法向取绝对值最大特征值对应方向；亮脊和暗谷分开。σ随当前输入图上的光学宽度缩放，不固定套用1～3。当前独立实现不包含原论文非对称剖面偏差校正，不能叫完整“无偏测量”。 |
| Frangi/Hessian | 用作脊线候选增强。暗沟不直接等于绳体中心；强响应也可能属于绳股高光。 |
| CLAHE/Retinex | 不规定“必须做”。增强可能同时放大噪声/绳股纹理，过曝和不可见区域不能靠增强恢复。本次用局部均值/方差归一化，但未做原灰度与CLAHE的独立消融，不宣称已证明其优于其他预处理。 |
| Gabor与传统连接 | 项目早期已尝试Gabor、Hessian与多候选路径。本轮把旧特征放进共同连接器，避免把重复方法包装成新突破。 |
| Ariadne+ | 分割＋图路径构造的思想更接近“同一根绳的连接/身份”。其散布线缆场景与密集反光卷面有差异，不直接套用预训练权重并保证效果。 |
| YOLO缺陷/排线异常检测 | 目标框或异常区域不等于中心线，更不等于新层时间。当前不优先再叠一个框检测器。 |
| 三维分析合成 | 可作后备研究；几何、反光与遮挡参数尚不确定，不能先假定拟合出的螺旋就是实测轨迹。 |

主要参考：[Steger作者技术报告](https://mv.in.tum.de/_media/members/steger/publications/1996/fgbv-96-03-steger.pdf)、[MVTec高斯线提取说明](https://www.mvtec.com/doc/halcon/13/en/lines_gauss.html)、[scikit-image脊线算子](https://scikit-image.org/docs/0.25.x/auto_examples/edges/plot_ridge_filter.html)、[Ariadne+作者实现](https://github.com/lar-unibo/ariadne_plus)。

用户给的[ParadoxRobotics实现](https://github.com/ParadoxRobotics/Steger_line_algorithm)确实存在并带GPL文件；本轮使用独立公式实现，没有拷贝其代码。[CN117611544A](https://patents.google.com/patent/CN117611544A/en)主要是卷筒排线异常定位/线段斜率分析，[Wacker与Denzler 2013](https://www.sciencedirect.com/science/article/abs/pii/S016786551300038X)研究绳表面结构/外观异常，两者不能直接作为本项目入卷身份或施力时刻精度的证据。

## 实验A：单图训练健全性——已完成

只用原训练f246，两个最终1200步模型均恢复了人工提示段之后的可信路径：

| 指标 | 原BCE | 平衡BCE＋Dice |
|---|---:|---:|
| 提示之后可信路径覆盖（5原像素容差） | 100% | 100% |
| 已输出路径的5像素贴合度 | 100% | 100% |
| 与人工参考的距离P95 | 1.141 px | 0.835 px |
| 全参考覆盖，含提示之前的自由段 | 81.96% | 81.96% |

这不是物理亚像素精度。平衡损失输出也不是经过校准的概率。原BCE同样成功，不能声称只有改损失才救活模型。

另把人工监督栅格直接交给固定解码器作独立oracle检查，得到约99.57%的提示后覆盖，说明这张图的目标栅格和解码器可以配合工作。**该项使用了GT，不计为模型识别能力。**

结论：链路能学会一张图，V9不是“任何输入都不可能学会”。但该结果不能单独区分训练预算、跨样本干扰与身份表达的影响，也不能证明新增更多标签就能解决问题。

### 固定窗口的提示干预——已完成

另做两个最终模型×三种条件，共6次推理：基线、8维全局描述符置零、网络全局/局部seed通道同时置零。RGB、九窗、独立宽度、解码锚点均不变，未重新训练。六次提示后覆盖和贴合仍为100%；基线逐值复现原导出。去全局描述符后误差P95有所增大，说明响应不是完全不依赖它；去网络seed通道后路径仍好，也不能证明模型学会了目标身份。

**这里只干预网络输入，原人工seed仍用于裁窗和解码。不能称“没有seed也能识别”。** 该结果更接近“能记住这张图”，下一阶段必须用来源隔离与目标身份测试，而不能把单图100%当作成功验收。

## 实验B：传统候选与共同连接器

方案先冻结再运行。仅输入原图、人工标出的悬空自由段和独立图像宽度，不能用目标中心线/法兰边界引导路径。新方法在分辨率为原图一半的自由段定向条带上计算，避免12MP全图逐点处理；按当前分辨率修正σ。

三个新方法均要求对应亮脊峰点支持：Steger式支路实际使用Taylor像素内偏移有效性，其余使用各自法向非极大值抑制。所有路径坐标仍经统一列峰细化，不能冒称已经执行完整Steger条纹偏差校正。暗谷只诊断，不自动作为绳中心。

共同连接器保留多假设，但评分固定取图像分数第一名，不用人工GT从候选中挑最好的。遇到缺口拆段，不画穿过缺口的“实测线”。旧V3支路保留其较窄支持范围，需单独报告；这是旧特征＋新共同连接器，不是旧软件完整回放。

已经完成固定18张×4方法，共72份结果。3种新方法还增加了真实重采样上下文，支持检查涵盖局部均值/方差与导数滤波，防止图外零填充制造假脊。常量图斜向跨图像边界、真实可见锚点保留均有合成回归。

**结果没有达到可部署要求，也没有证明Steger/Frangi优于已有特征。** 下表全部为固定第一候选；不是挑选与GT最接近的分支。

| 方案 | 训练10张路径覆盖 | 留出8张路径覆盖 | 留出8张预测贴合度 | 留出空路径 |
|---|---:|---:|---:|---:|
| 归一化单尺度Hessian | 15.62% | 27.26% | 23.32% | 0/8 |
| Steger式多尺度＋Taylor峰点 | 13.81% | 29.58% | 28.06% | 1/8 |
| Frangi式多尺度 | 17.29% | 24.48% | 32.39% | 0/8 |
| 已有V3特征＋共同连接器 | 20.62% | 29.64% | 50.81% | 0/8 |

覆盖/贴合均为提示之后可信参考、5原像素容差、按弧长统计。0/8空路径只表示每张生成了候选，不表示候选正确。部分标注不是全图所有绳的穷尽真值；贴合度不能解释成已验证的全部实例分类精度。

为避免混合来源掩盖问题，留出集再分开看：

| 方案 | 原留出6张覆盖 / 贴合 | 新留出C04、C05覆盖 / 贴合 |
|---|---:|---:|
| 归一化Hessian | 32.68% / 27.31% | 15.95% / 14.25% |
| Steger式 | 23.55% / 22.20% | 42.19% / 41.12% |
| Frangi式 | 21.55% / 33.37% | 30.59% / 31.05% |
| 已有V3特征 | 26.21% / 52.44% | 36.82% / 48.59% |

新三种支路的留出参考观测支持约95.83%（新C04/C05约89.37%），旧支路为100%；两者归一化支持保护和法向范围不同。所有支持外参考仍计入覆盖分母，不通过裁掉困难段提高分数。因此这是四个配置完整流程的对照，不是“只换特征、其他每一项都相同”的严格孤立因果实验。

**图像检查发现的主要问题**：高光/绳股/绳体中心不总在同一条线上；随着曲线转向与明暗变化，第一候选会偏离人工确认轨迹，有的向邻纹偏移，有的提前停止。连续、平滑不等于身份正确。不同方法在不同图片上互有好坏，不能根据某张最好看的图选胜者。

这比V9完全空输出提供了更多图像候选，但仍不是足够准确的识别。V9与本轮的响应、裁剪和解码不同，不能把它们的数值差直接归因为某一个滤波器的提升。

## 根据结果调整下一阶段方案

**不继续仅靠更换脊线滤波器或调低门槛。下一阶段改为“候选特征＋指定绳路径/连接模型”的混合路线。** 下列为后续方案，尚未训练或部署：

1. 保留已有速度较快的特征作为基础候选，Steger/Frangi保留为可选证据，不将任何响应峰直接命名为绳中心或物理切点。
2. 改变模型的任务表达：不是整幅图独立预测“哪里像绳”，而是由自由段起点/方向出发，预测逐段位置及连接关系。保留空间对齐的上下文，替代仅8维全局池化；使用按局部宽度归一化的相对坐标，降低绝对像素宽度和安装位置依赖。
3. 研究按截面的中心位置分布、走向与可见性联合输出，再用路径搜索保持连续性；同时训练停止/未知处理，不能因强制连续性跨过不可见区域。未知尾段继续排除，不自动生成“真值”。
4. 先做同图可学性、保持RGB/裁窗不变的提示干预、从现有可信纹理构造明确的邻绳诱饵检查。通过之后才在整段来源隔离的评估图上报告覆盖、贴合、换绳错误与拒识；不在评估失败后反复改门槛而覆盖历史。
5. 只有路径/身份稳定后，才接独立边缘几何判断到边，并恢复新层/首圈结束的时间验证。未通过时仍不接运动控制。

本轮不要求用户追加标注。只有下一阶段发现现有资料中明确缺少某种可观测信息，才提出少量、具体位置的复核需求，而不是泛泛要求再收集一批图片。
