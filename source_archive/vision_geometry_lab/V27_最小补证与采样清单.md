# V27 最小补证与采样清单

下一轮现场投入应先取得可判定的信息：保留相机已产生的帧，确认短曝光下是否看得清同一处材料纹理，并为真实入层提供独立观察。不要先购买更大模型或继续录制大量同类模糊视频。以下仅为授权人员执行的采集计划，本轮代码不连接设备、不改采集程序，也不解除运动锁。

## 先核对现有采样链路

现有[录制程序](D:/precise_arrangement/vision_prototype/dual_camera_recorder.py:103)默认`target_fps=10`，按接收时间间隔主动选择保存帧，使用MJPG AVI；这是保存目标，不是相机最大帧率。[相机接口](D:/precise_arrangement/vision_prototype/live_camera.py:171)设置3个SDK缓存及`LatestImagesOnly`取流策略。接口拿到图像后记录主机单调时钟，再将原像素格式转换为BGR。主机接收时间不是曝光时间，录像无重复帧也不能证明采集链路没有丢帧。

下一次独立采集需要分别记录四层，而不是仅看界面左上角fps：

| 层级 | 要记录的量 | 如何核查及结果栏 |
| --- | --- | --- |
| 相机实际产生 | 设备帧号、设备时间戳、时间戳单位或频率、曝光和触发状态 | 由授权人员查询本型号实际支持的节点或MVS读回；频率未验证则填未知。实际频率：____；依据：____ |
| SDK实际交付 | 每个交付帧号、主机接收时刻、超时、传输错误、SDK覆盖或丢弃计数 | 与设备计数对齐。若设备没有相应统计，明确哪些损失不可见。实际频率：____；缺口：____ |
| 实际保存 | 保存帧号、对应设备帧号、保存入队和完成时刻、队列水位、主动跳帧和写盘失败计数 | 区分主动降采样、取最新帧覆盖与写盘滞后。实际频率：____；主动跳过：____；失败：____ |
| 算法实际处理 | 消费的保存帧或设备帧号、处理起止时刻、结果首次可用时刻 | 不把显示刷新率当输入率，不用处理结束时间替代曝光时间。实际频率：____；延迟范围：____ |

先保留当前参数和恢复方案，再由工程人员准备不耦合耗时识别、能记录完整接收序列的独立采集模式。按短段验证磁盘、总线和队列负荷，不能直接把限制改成很高的数值就宣称恢复了原始采样。若仍使用取最新帧策略，必须记录其影响，不能将输出标成逐帧无损时序。

## 区分三种ROI

- **软件ROI**是在收到完整画面后裁切，主要减少存储或分析量，不自动减少传感器读出时间。
- **相机硬件ROI**由传感器及相机输出设置决定，可能减少读出或传输量。收益受该型号传感器读出、ROI高度、曝光、帧率限制、像素格式和带宽影响，需实际读回及计数验证。
- **自动曝光ROI**只指定自动控制参考区域，不等于图像输出裁切，也不等于提高帧率。

ROI与曝光等因素影响帧率可参考[Basler的ROI说明](https://docs.baslerweb.com/image-roi)及[帧率限制说明](https://docs.baslerweb.com/resulting-acquisition-frame-rate)。它们说明一般工程关系，不是海康MV-CH120-10UC的性能保证。不得照搬别的品牌节点名；本项目节点、可写范围、步进和恢复方法均由授权人员通过海康手册与现场读回确认。

## 成像对照每次只改一个主要条件

先固定相机位置、焦点和光路，保留原设置，选同一可辨自由绳区域做短段对照。优先比较基线与缩短曝光后的画面，检查纹理是否更清晰、饱和是否减少、暗处是否仍有信息；增益和灯光变化均须单独记录。不要只追求平均亮度一致或保留点数增加。

当基线与短曝光都出现明显镜面反光时，再借用适合现有光路的偏振方案进行角度对照。偏振有抑制部分反射、过曝的可能，但可能损失光量；必须按当前金属表面和照明验证，不能承诺装上就有效。[Baumer的偏振成像原理说明](https://www.baumer.com/ch/en/service-support/technology-highlights/polarization/a/Polarization)

局部匀速、短曝光的拖影预算为`b_px ≈ |v_image_px_s| × T_exp_s`。尚未确认材料像素速度时只保留变量或独立参考给出的范围，不能把某个LK分支的24.98 px代入作为已知真速度。提高帧率缩短的是帧间间隔，不自动缩短每帧曝光拖影。

对纯周期纹理，若没有额外先验而只选最近相位分支，可用`|Δs| < P_texture_px / 2`设计采样对照。`P_texture_px`是图像轴向可见纹理周期，不是配方捻距，也不是卷面整绳间距。这不是所有跟踪算法的通用硬限制；即使满足，也不能消除绳体自转和轴向进料之间的相位耦合。

每个条件留同样长度的小段，评价以下四项：未饱和且有细节的区域、可辨材料纹理、拖影、盲化跨帧对应能否确认。若主要变化只是更亮或相关峰更尖，而人仍只能看到重复相位，不扩大采集数量。

## 三类独立证据分别补齐

| 要确认什么 | 最小可操作证据 | 不能替代它的量 |
| --- | --- | --- |
| 同一材料跨帧位置 | 先用本轮盲化包复核3帧中的少量独特绳纹；不可辨时，在经过授权的隔离试验样件上使用不脱落、不改变工艺的非均匀薄标记，或借参考特写相机 | 相同螺纹相位、LK前后向一致、算法自报可见或多个算法一致 |
| 真实新层开始t1 | 连续拍到真实入卷处最后明确旧层和首次明确爬层；记录观察区域及时间区间 | 侧缘稍后出现的台阶、工人按钮/敲击、排线臂换向或历史估计秒数 |
| 正向累计一整圈 | 经核验的工字轮编码器，或与工字轮刚性同步且可见的角度参考；验证方向、比例及无相对滑动 | 命令点动某角度、绳上材料标记、捻绳机转速、未标定的表观纹理速度 |

标记只在经过授权的停机与隔离条件下由现场人员操作，禁止在运行机构旁伸手贴胶带。停机—点动序列可验证材料身份和静态几何，但暂停可能改变张力与排布；不能用它代替连续生产的t1时序真值。

参考相机或角度日志必须与主相机做时钟对齐，记录固定偏移、漂移、曝光与接收延迟的不确定度。两路SDK主机接收时间接近不等于同时曝光。操作者键盘/已有日志只记`operator_observation_time`，保留反应时间和视线延迟；本轮不为取得按钮线索擅自接CX输入。

若原视角持续看不到实际爬层入口，应优先借测一个受防护隔离的参考特写或局部高度测量方案，先验证能否看见事件。不要求先恢复完整同根绳路径才允许验证高度事件，也不在样件验证前承诺购买设备。

## t2保持条件计算而非上线倒计时

主验证仍是可信t1加有方向的独立连续角度：从t1到t2，工字轮按工艺认可方向累计转过`2π`。转角准确不能修复t1起点错误。

若考虑用真实材料线速度积分代替角度，至少还要确认测速位置至入卷点之间的自由绳储长、透视及标定、时钟、伸长和打滑、入卷点周向位置变化、新层中心线半径和爬层交叉路径。按相同伸长口径，可作长度守恒诊断：

`L_wound(t) = ∫v_in dt − [L_free(t) − L_free(t1)]`

只有固定入卷几何、规则螺旋、无滑移等条件成立时，一圈长度才近似`sqrt((2πR_center)^2 + p^2)`。半径使用绳中心线有效半径，不直接使用最外包络；`p`是该圈的轴向螺距，不混用钢丝绳自身捻距。

在更简化的恒速固定几何条件下，`T≈2πR/v`。时间预算至少列出：t1区间宽度、R误差、v误差、自由储长变化、爬层几何、时钟对齐、结果首次可用延迟、执行机构动作延迟。仅作一阶保守敏感性估算时，半径与速度贡献可写为`|δT|≲T(|δR|/R+|δv|/v)`；其他项仍需单列，不能假设互相独立后随意相消。当前没有可信数值的项保持未知，t2仍不可用。

## 下一笔投入的判定顺序

1. **修正已证实的实现问题**：坐标、点ID、帧对、首次可用时间或统计分母出错，先修复并重测，不换模型掩盖。
2. **恢复可验证的采样**：采集比保存快而应用主动丢弃时，优先准备独立完整接收记录；同时确认磁盘、传输和队列是否承受。
3. **改善成像**：更密采样仍无法辨认独特纹理，优先短曝光及光路小对照；不要继续堆同类录像。
4. **补独立真值**：材料可辨但没有核验对应，先标少量点；入层只见延迟线索，先借参考视角或高度方案；一圈进度缺依据，先借测角度参考。
5. **再决定身份算法**：只有真实候选出现在图中、短时材料对应能被独立确认、正确与相似候选可以公平比较时，才值得扩大身份算法实验。

如果固定预算内候选仍只是相位分支、清晰对应无法形成，或正确候选根本未进入视野，就停止继续换更大模型和训练分类器。完成失败归因与可复核交付后，把资源投入新增可观察信息；不把跑通程序、更多保留点或更平滑曲线当成物理验收。
