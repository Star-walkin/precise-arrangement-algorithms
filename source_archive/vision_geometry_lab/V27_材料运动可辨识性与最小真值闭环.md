# V27 材料运动可辨识性与最小真值闭环

2026年10月6日。本轮已经完成配对轨迹审计、盲化材料与t1复核工具、全部60组条带表观运动诊断。**原来的24.98 px与1.43 px首先是不同接受点集合的比较问题；统一共同点后，两方法中位数为24.98 px与27.36 px。但个别点仍有大分歧，且条带呈现多周期解，不能据此确认真实材料运动。**

下一笔投入优先用于小规模独立真值闭环，配合恢复可验证的采样和短曝光成像对照，不继续扩大身份网络或堆倒计时。先用本轮已有干净数据复核少量材料点；如果只能认出相似螺纹，立即停止扩标该类图像，转向有独立参考的短段采集。对最终目标，最有价值的新增证据仍是直接看见真实入卷处的爬层区间，而不是侧缘稍后出现的台阶。

本报告不提供材料身份准确率、真实线速度、可用t1或可用t2。没有连接相机、光源、PLC或运动设备，没有打开保留集，没有修改线上模型、报警门槛、采集程序或动作锁。

### 几何和曝光能解释多少

两个时刻分别使用已到达的帧240与帧242独立拟合；几何年龄93.040 ms与0 ms，无未来插值。直线方向12.302037°→12.324084°，仅变化0.022047°；光学宽度22.534→22.812 px，约增加1.232%。

固定裁块中心作为参考，只补偿独立直线的转动和法向摆动，不跟随纹理、不按线段端点拉伸、不使用追踪点拟合运动。补偿后配对差中位数仍为−2.290558 px，ID 0和4的大分歧也基本不变。故这次已测直线摆动不能解释大幅轴向分歧。未标定透视、绳体自转、形变及尺度误差仍未排除；光学宽度变化不是已测物理绳径变化。

共同5点中，ID 0、2、4、6在两个方法、两个端点的9×9 patch饱和比例为6.17%～18.52%，对比度96～170，通过固定粗质量条件；ID 9的饱和比例27.16%～35.80%，不通过25%条件，但仍保留在原始分母。不能说巨大差异仅因这两个patch全过曝，也不能凭通过粗质量条件排除反光、模糊和周期误配。曝光时间、增益的历史逐帧读回不存在，不能反推它们没有变化。

另外，LK256窗口21对应约84原图像素，而原图LK窗口41对应41像素。该旧对照同时改变细节和有效窗口范围，不能只归因于分辨率。

### 纹理周期给出多解而不是真值

同一原图条带、同一帧对的固定坐标二维ZNCC扫描范围为±128 px，保留的候选按位置排序为：

`−113, −84, −56, −27, 1, 30, 58, 87, 115 px`

空间自相关出现29、57、86、115 px等重复峰，还存在102 px峰；不能把最短29 px无条件认定为唯一基本周期。它们是图像轴向纹理重复距离，不是配方捻距或卷面整绳间距。

- ID 4的−85.807 px分歧接近−3×29 px，残差1.193 px；对86 px重复峰的残差为0.193 px。整数周期分支是有图像支持的解释，但尚不知哪一路正确。
- ID 0的24.477 px与29 px相差4.523 px，不能把它强行归为恰好一个周期。局部窗口、反光、非刚性及采样差异仍可能参与。
- 接近零的1 px峰也有竞争峰，不能认定绳真的近零进料；非零峰也不能自动认定为真实运输。

每个共同点、两种坐标配置、四个带的完整[周期关联记录](D:/precise_arrangement/vision_geometry_lab/outputs/v27_material_observability/v27_20261006_002/period_join/all_common_point_periods.jsonl)与[左侧明细](D:/precise_arrangement/vision_geometry_lab/outputs/v27_material_observability/v27_20261006_002/period_join/left240_frame241_242.json)均已导出，未用偏好的速度限制搜索。超出±128 px的分支仍可能存在，不能把有限搜索当物理上界。

## 条带诊断的实际作用与局限

从同一自由段保留原始像素采样尺度：固定几何参考，沿轴1 px采样，不每帧拉伸；保存原图映射、有效掩膜、几何年龄、二维条带和三个固定横向窄带。只在窄带内部计算有效像素均值作一维对照，不把整根绳一开始平均成一条信号。

采用按有效重叠重新计算均值和方差的ZNCC，另做加窗、零填充FFT相位相关并保存掩膜自身相关。饱和或过暗原像素、插值跨过无效像素、低方差、重叠不足均有显式诊断。FFT零峰可能来自固定高光或掩膜，峰高不是身份正确概率。方法依据是[OpenCV平移相位相关说明](https://docs.opencv.org/4.x/d7/df3/group__imgproc__motion.html)，本实验保留多峰而非直接使用单一argmax。

| --- | ---: | ---: |
| 多个相关候选 | 1,794 | 2,179 |
| 无可用候选 | 505 | 144 |
| 仅一个表观峰但未确认材料 | 41 | 17 |

补偿减少了无法比较的条带，却主要恢复成多解，而非恢复成唯一材料对应。不能把可用数增加当作身份提升。全部60组核心计算及条带/PNG写出约105.34秒；这是离线批处理耗时，不是相机端到端实时性能。`t_available`与`actual_live_t_available`均为空，接收时刻只记为源输入可用下界，不将输出回填成在该时刻已经知道。

固定坐标的505次拒识中，188次最大有效相关低于冻结门槛，170次所有位移都因重叠/方差不足而无效，118次当前几何有效但该固定条带没有有效像素，22次轴向纹理方差不足，7次几何不可用。补偿后的144次分别主要为123次相关不足、14次代价全无效和7次几何不可用。它们是保存证据的诊断分箱，不是已确认的曝光、遮挡或身份失效原因。补偿也使81个原本有候选的帧对变为无候选，high窄带可用数下降，不能宣称全面改善；详见[分组解释与读取哈希](D:/precise_arrangement/vision_geometry_lab/outputs/v27_material_observability/v27_20261006_002/posthoc_presentation/strip_interpretation.json)。

### 合成实验揭示的不可辨识性

渲染器使用圆柱表面坐标及真实螺旋纹理相位`2π(s−u)/P + k(φ−θ)`，不是随意滚动亮度。已测试纯平移、纯自转无进料、平移加自转，以及非周期材料标记/反光/遮挡混合，并另外给出固定掩膜诱发FFT假零例。

理想螺旋纹理中，不同的轴向平移u和自转θ能够给出相同图像。示例真实平移77 px、周期24 px时，−115到125 px的一串间隔24 px的位移均可具有满相关。实现保留多解，不输出唯一速度。非周期材料标记在可见时才可能破除部分对称，合成成功不等于现场成功。证据见[合成机制与多峰](D:/precise_arrangement/vision_geometry_lab/outputs/v27_material_observability/v27_20261006_002/synthetic/report.json)。

[Vallan与Molinari的钢丝绳相位测量论文](https://iris.polito.it/bitstream/11583/1897848/2/postprint%20draft.pdf)也说明其相位展开依赖静止启动和运动变化条件，噪声会造成整数分支错误。现有录像不能仅靠视觉近零位移自证静止，不能直接套其展开得到绝对进料量。

请先读[操作说明](D:/precise_arrangement/vision_geometry_lab/experiments/v27_material_observability/盲化材料与换层复核使用说明.md)，本次先做少量，而不是要求把84张全部猜完：

## 条件分支的停止位置

CoTracker3本轮未推理，没有填写虚构性能。已核对[固定官方commit的online接口](https://github.com/facebookresearch/co-tracker/blob/82e02e8029753ad4ef13cf06be7f4fc5facdda4d/cotracker/predictor.py)：默认窗口16、步长8，内部resize，支持网格不是原556种子。若以后运行，必须记录批次最大源时刻、首次输出与历史修订；10 fps下8个新帧约0.8秒，不能当零等待。

官方[许可](https://github.com/facebookresearch/co-tracker/blob/82e02e8029753ad4ef13cf06be7f4fc5facdda4d/LICENSE.md)具有非商业限制。企业项目适用性目前未获确认，已经向用户询问，因而本轮不下载执行权重或集成，不把“离线研究”自行认定为已获授权。权重哈希为空、效果未知；未删除TAPNext++已有部分下载，也不将其下载失败改写为模型失败。

固定特征材料指纹的候选可分性分支也未进入：缺少可信跨帧材料对应，无法给哪个候选是真对应贴标签。本轮没有训练分类器、没有伪标签扩增。复核得到清晰材料对应后，才值得做一次小规模固定特征比较。
