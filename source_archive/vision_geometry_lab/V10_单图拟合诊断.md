# V10：先检查一张已知训练图是否能学会

范围：仅离线优化健全性检查，不接相机/光源/PLC/伺服，不替换实时模型。

## 问题与约束

V9在训练图本身也没有恢复有效的连续入卷路径。因此，不能直接把失败解释成“标注不够”或“泛化不好”。本实验先固定一张已有训练图 `dual_20260924_111500__left__f00246`，检查当前模型和监督在较充分训练后能否拟合这张图。

本图对应原始视频24.6秒、界面第247帧。人工自由段提示仍作为输入，故不是无提示的全自动识别。只读取这一张训练图、其标注与质量文件；不读取留出图像/标签，不打开9月25日后备盲测。

## 两组对照

两组相同条件：V9原架构、原图细节输入、九个仅由自由段提示决定的窗口、8个基础通道、batch=2、Adam学习率0.001、CPU两线程、随机种子20260927、相同初始参数和相同1200步窗口序列。

只改变损失：

1. `masked_bce`：原掩膜BCE。
2. `balanced_bce_dice`：对每个输出头，以有效像素中的软目标质量分别归一正、负BCE，二者等权；再与掩膜softDice各占一半。若本批没有正目标，只计算有效负样本BCE。若完全无有效监督，损失和输出梯度均为零。

未知区不是背景。两组都继承相同的排除掩膜；C07/C08的可信截面规则没有被取消，但本次选中的f246采用其原有历史质量多边形，不能声称已具有新的C7截面确认。

加权BCE和Dice的输出是响应图，**不具有经过验证的概率校准意义**。两组仍采用同一冻结的0.5解码门槛，不能针对结果临时降低门槛。

每300步保存一个诊断检查点；最终结论只使用预先指定的第1200步，不择优、不早停。训练输入/目标只缓存一次，以免每步重复生成全图掩膜。

## 评估规则

- 原V5保守路径解码器不改动。
- 绳宽只由原始RGB与自由段提示独立计算，不输入人工两侧边界宽度。
- 原V6路径规则不改动：5个原图像素容差，按弧长统计覆盖与贴合度。
- 质量未知区同时从参考和预测的精度评分中排除；窗口未覆盖的可信参考不能删除。
- 同时记录普通BCE与中心线响应，避免把加权训练目标下降误说成路径正确。
- 所有指标均为**这张训练图的拟合结果**，不代表跨绳径、卷径、照明或相机位姿的泛化。

## 冻结与状态

协议：`outputs/v10_single_fit/protocol.json`。冻结后不修改原V5～V9代码、原图、标注、质量文件；执行前后检查依赖和数据哈希。

已完成真实1200步配对实验；新增5项loss/未知区/单图范围单元测试通过。初始参数、采样序列、实际输入、监督元信息逐项相同；冻结代码、原图、原标注、质量文件前后哈希复验通过。全程没有读入留出图像或标签。

## 结果：能拟合这张训练图，但不能据此宣称泛化

固定最后1200步、固定5像素容差下：

| 单图提示段之后的可信参考 | 原掩膜BCE | 正负平衡BCE＋Dice |
|---|---:|---:|
| 路径弧长覆盖 | 100% | 100% |
| 预测路径5像素贴合度 | 100% | 100% |
| 评分内预测长度 | 1385.45 px | 1384.65 px |
| 参考到预测距离P95 | 1.141 px | 0.835 px |
| 可信中心目标区域响应均值 | 0.740 | 0.983 |
| 可信中心目标区域响应≥0.5比例 | 94.04% | 100% |
| 统一普通BCE诊断 | 0.1262 | 0.2008 |

独立自由段光学绳宽22.575像素，由RGB＋提示单独测得，不使用人工两侧边界。两组的可信提示段后路径均被九窗覆盖，评分分母没有因窗口或难点而缩小。

这里的“100%”仅指**同一张反复训练过的图、人工明确可见且未被排除的提示段后参考、5个原图像素容差**。这既不是整幅图的识别准确率，也不是全部绳索实例识别准确率，更不是毫米/实体中心线精度。未知区在响应图上仍有很多亮响应，局部监督不能约束整幅背景；当前保守seed解码只选出其中一条路径。

人工提示之前的上游自由段不在此解码器的输出目标内，所以不能把提示段后100%说成全图全部参考都完整识别。全部指标和未裁剪轨迹保存在原始JSON中。

两组均成功拟合，故本次不能证明平衡损失优于原BCE；也不能把0.835像素的标注贴合值说成已经验证的物理亚像素测量精度。加权组普通BCE更高但路径仍贴合，说明不同优化目标的损失大小不能跨组直接评优。

## GT目标oracle诊断：检查解码链是否本身失配

另做了明确标为**GT输入、非模型预测**的诊断：把这张图的同一监督栅格按九窗拼接，未知区以无证据处理，再使用同一个独立RGB绳宽、固定V5解码器和V6评分规则。

结果：目标中心响应峰0.9255，提示段后覆盖99.566%，贴合度100%。这说明该图的目标sigma/缩放与原解码器组合能够恢复路径，并不存在“即使完美输出监督也完全无法解码”的整体实现故障。它不能计入模型成绩。

## 本轮可以与不可以得出的结论

1. 已排除一种基础障碍：现有V9输入/目标/网络/解码链并非完全无法表达这张弯曲入卷轨迹；原BCE在充分单图优化下也能学到。
2. V9的失败仍然真实存在。本次把10张改为1张，并将300步延长到1200步，每张图的训练暴露量显著增加，因此不能单独把进步归因于延长步数或改损失，更不能推断在10张上延长训练一定解决泛化。
3. 下一步应优先检验指定绳身份、空间信息与连续路径约束，而非立即扩大标注量。需要来源隔离评估才可宣称跨场景改善。
4. 本次未检验独立法兰边界、到边事件、新层开始、工字轮整圈相位或施力时间，不部署、不解除运动锁定。

运行时间：原BCE优化循环约384秒，平衡组約414秒；每组单图监督缓存约33秒。无输入缓存的单图九窗推理分别约948ms/819ms，存在系统负载差异且未计独立宽度/解码/相机/显示，不用于声称两种损失在速度上有优劣或已达到实时。

## 固定窗口的输入干预：单图成功不等于学会指定绳身份

追加只读诊断，另行冻结协议，保留两个最终1200步检查点，不训练、不选模型，只进行6次九窗推理：

- 基线：原RGB与原seed通道。
- 全局描述符置零：原全局/局部输入不变，仅把编码后的8维全局描述符置零。
- 全局与局部seed通道置零：两种输入的第4通道置零，全局描述符重新计算；RGB不变。

**三种条件的九窗位置、原图坐标、输入尺寸、独立RGB绳宽及路径解码seed完全不变。** 因此这里没有取消整个系统对人工seed的依赖，仍然由原seed选窗并锚定解码。这个实验只检查网络提示通道和池化描述符在这张训练图上的必要性。

两组基线都逐值复现了原最终导出，最大绝对差为0。六种输出的提示段后覆盖和5像素贴合度均为100%。差异为相对于同一检查点基线的响应绝对差：

| 模型 | 干预 | 中心响应全图均差 / 最大差 | 绳体响应全图均差 / 最大差 | 参考距离P95 |
|---|---|---:|---:|---:|
| 原BCE | 无 | 0 / 0 | 0 / 0 | 1.141 px |
| 原BCE | 全局描述符置零 | 0.05537 / 0.71187 | 0.05318 / 0.97373 | 2.653 px |
| 原BCE | 两级seed通道置零 | 0.000760 / 0.18213 | 0.000837 / 0.58719 | 1.118 px |
| 平衡BCE＋Dice | 无 | 0 / 0 | 0 / 0 | 0.835 px |
| 平衡BCE＋Dice | 全局描述符置零 | 0.05359 / 0.87047 | 0.04608 / 0.96666 | 1.538 px |
| 平衡BCE＋Dice | 两级seed通道置零 | 0.002366 / 0.60468 | 0.002383 / 0.89400 | 0.822 px |

全图均差包含窗口外恒为0的区域，因此原始JSON还记录了仅窗口覆盖区的均差：两级seed置零时，中心响应均差分别0.00334/0.01038；全局描述符置零时为0.24301/0.23520。不能把被大面积窗口外零值稀释的全图均差当作局部完全不变。

解释：在**这张记忆过的训练图、固定原seed窗口和解码锚点**上，网络seed通道或8维池化描述符并非获得5像素内轨迹所必需。响应确实改变，且去描述符后的P95变大，所以不能说网络完全忽略这些输入。更不能宣称无seed也能识别、能够追踪任意指定钢丝绳，或已经证明跨场景泛化。该诊断反而说明：单图拟合成功还不足以证明模型学会了活动绳身份与整体走向，下一阶段应继续围绕这一点设计来源隔离的实验。

新增3项输入干预单元测试通过；与之前5项合计8项本轮专用测试，不替代整个项目回归。
