# V14：中心线与双侧边界联合监督对照

日期：2026-09-29。范围：独立离线几何实验；不接相机、光源、PLC、排线臂或伺服。

## 1. 本轮要回答什么

上一轮发现，灰度跃迁与有限切向平移对齐的纹理差异能提供候选证据，但不足以单独确认同一根绳，也尚未实现完整的暗面终止检测。因此这轮先做一个可归因的改动：在原中心线任务旁边增加双侧边界监督，检查共享图像特征是否会改善新入卷绳路径。

这不是完整的“暗面终止＋纹理周期”算法，也没有同时加入新的纹理输入、精修算法或强制等宽约束。用户提出的纹理方向保留为后续独立消融，不用本轮结果替它下结论。

## 2. 如何确保是同条件对照

两组均从相同随机种子重新初始化相同网络，包括新增的两个边界输出通道；不是拿旧模型和新训练模型直接比较。

| 项目 | 仅中心监督组 | 联合监督组 |
|---|---|---|
| 输入、共享网络、初始参数、样本顺序 | 相同 | 相同 |
| 原中心概率与方向损失 | 保留 | 保留 |
| 真实图像双边损失 | 权重0 | 权重0.5 |
| 合成身份样本 | 原中心＋方向监督 | 原中心＋方向监督，无虚构边界 |
| 中心线解码器 | 原V11版本 | 原V11版本 |
| 宽度损失、纹理特征、边界排序修复 | 不加入 | 不加入 |

单图每组1,200次更新，真实与合成样本各600次；通过机制检查后，多图阶段每组重新初始化、训练2,400次。多图真实样本固定10张，每张120次更新；另有1,200次合成更新。使用最终检查点，不挑最佳迭代。

两个边界独立预测，允许出现交叉并如实计错。宽度仅由原始双边间距导出，用于诊断；本轮**没有独立的宽度回归损失**，也不强迫中心处于双边正中。这里的宽度是固定条带法向投影间隔，不是物理绳径。

## 3. 评分与停止条件

先在原先指定的左相机 f00246（界面第247帧，24.6秒）检查模型能否学会可信标注。它是训练图，不是泛化验收。

中心路径按原图像素的弧长覆盖率、5像素内预测路径比例评分。双边按可信下游截面计数，误差阈值为原图5像素；不同图片的路径长度不同，合并截面比例不是逐图成功率。

预先固定的机制门槛包括：两组中心覆盖/精确比例均至少90%，联合组下降不超过2个百分点；合成身份测试至少90%；联合组两边各85%截面误差不超过5像素、投影宽度平均相对误差不超过25%、边界交叉不超过5%、双边夹住可信人工中心的比例至少85%。另检查预测完整性及完整可信参考边界的可评分支持，不能删掉难段抬高得分。

这些是模型机制筛查条件，不是设备动作验收指标。未达到门槛就保留失败，不修改本轮阈值后重报成功。

C07/C08只使用用户确认到C7的可信中心与对应可信边界；未知部分不当背景。推理只看图像有效范围，不使用人工路径或质量掩膜来限定预测位置。人工自由段种子仍是输入，因此仍不是全自动系统。

## 4. 结果

**结论：双边可以学会，但本次共享特征的联合训练没有通过“不得明显损害中心线”的预设条件。没有进入8张开发留出图的推理/评分，也没有替换实时模型。**

### 4.1 单图机制检查通过

| 指标 | 仅中心监督 | 联合监督 |
|---|---:|---:|
| 种子后可信中心路径覆盖率 | 100% | 100% |
| 预测路径中距可信中心不超过5px的比例 | 100% | 100% |
| 合成双提示身份机制测试 | 16/16 | 16/16 |
| 双边分别在5px内的可信截面比例 | 未监督，不作为边界对手 | 100% / 100% |
| 投影宽度平均相对误差 | 未监督，不作性能比较 | 7.00% |

100%仅限**人工种子后**的可信路径；完整人工路径覆盖两组都约84.55%，不能写成整根绳自动识别100%。单图联合组没有边界交叉，所有可评分双边均夹住可信人工中心。

进一步的GT取整诊断显示：该图每条带行约4.23285原图像素，5px容差约1.18行；把人工双边分别取最近整数行，本身就有约7.30%的宽度相对误差。因此本图7.00%已接近这一特定取整参考，但7.30%不是数学下界，也不是模型成绩。这不构成物理绳径精度证明。

### 4.3 已定位的问题与尚未证明的原因

- 中心退步主要集中于同一右相机来源111143；f190、f130、f114分别少覆盖约155.58、37.91、5.98原图像素弧长，其他两图略有增加，总净损约191.48px。
- f190联合组在全部221个可信下游列均有输出，但其中41列同截面中心误差超过5px。这些坏列均没有5px内的固定候选点；原始概率最大值的5px命中也从98.19%降到81.45%。所以本例主要不是解码器从现成正确候选中选错。
- 这些坏列偏向条带正法向，平均偏移约+6.20px。**不能据此认定跳到了整根邻绳**；目前证据首先说明局部中心定位偏移。
- f190的宽度误差仅13.17%，双边夹住人工中心约98.17%，中心路径却仍退步。因此“宽度看似合理”或“双边夹住中心”不能单独批准识别结果。
- “辅助任务影响共享特征/梯度”是应检验的原因，不把它当成已完全证明的训练机制。尚无本轮留出泛化结论，也没有事件时间结论。

事后对最终联合模型做了同一次前向、同一训练图的两项损失梯度检查，仅计算共享主干，不更新参数。10/10张图的梯度余弦均为正（约0.035～0.609）；f190/f130分别约0.609/0.594。因此**在最终参数点没有观察到负方向梯度冲突**，不能把局部退步简单归因于两任务在该点相互对抗。加权边界梯度范数与中心梯度范数之比中位约0.947，说明辅助项也并非可以忽略。该检查不能回溯早期训练、Adam、梯度裁剪及跨样本作用。

### 4.4 后续处理方向

先保留已学到的双边能力，但不让它未经验证就改变中心任务。下一轮先预先固定一次**辅助权重0.5→0.1**的单因素机制对照，其他输入、目标、步数、样本顺序、解码器和门槛不变，检验辅助任务强度的影响；这个数值是待验证的实验设置，不是已找到的最佳权重。若相同来源仍退步，不继续扫权重凑通过，而转向**边界分支与中心主干隔离**的机制实验，检查能否保留边界能力而不损伤中心任务。

暗面过渡、纹理一致性仍作为后续候选排序/验证证据；应在自动候选上验证，不能用人工路径预先选好位置再宣称自动成功。若以后确实受输出量化限制，再单独验证亚像素边界解码；本轮不据GT诊断改写模型结果。

当前无需追加标注。先使用现有可信数据完成上述机制实验。
