# V27 材料对应与换层独立复核

这次复核只回答两件事：相邻画面里能否确认同一处真实绳纹，以及能否直接看见新绳开始爬上旧层。先做少量可信记录即可；无法辨认时记录“未知”，不要补猜。软件不连接相机或设备，不显示算法轨迹、候选事件时间或分数，不会发出动作指令。

## 打开与查看

双击 [复核V27材料与换层.cmd](D:/precise_arrangement/vision_geometry_lab/复核V27材料与换层.cmd)。在左上角选择随机编号的案例。状态行会说明当前是“材料跨帧对应”还是“完整录像t1独立复核”。

材料包有4个案例，每个21帧，保持原像素大小的灰度裁图；没有镜像、增强或算法画线。另有2个完整录像案例，各601帧，从第0帧开始，不预先定位到算法猜测的时刻。材料裁图不包含原片的全部视野，不能用它独立断定完整换层事件。

- **Ctrl加鼠标滚轮**缩放；**按住右键**拖动画面。
- 左右方向键或“上一帧”“下一帧”逐帧查看。光标在输入框内时，方向键保留编辑功能。
- “复核帧序号”从0开始，用于本案例内跳转；材料案例不会显示旧算法的片段名称或候选时刻。
- 播放只用于浏览。判断时间端点时请暂停、逐帧查看。播放速度不是测量时钟。
- 原图坐标、源文件哈希和接收时间会写进标签，画面上的缩放不改变标签坐标。

## 材料点先复核三帧

这里的“同一材料点”指同一段金属表面上的同一处细节，不是每帧看起来最像、最亮、或位于相同螺纹相位的位置。周期纹理可能有许多相似位置，不能直接把它们赋予相同身份。

1. 填写“复核人”。从材料案例的第0帧开始，只找1至3处自己能辨认的细节，例如不规则暗斑、细丝形态或与周围不同的纹理组合。
2. 同一处材料始终使用同一个ID，例如P01。左键点击该处，填写原图像素口径的“误差半径px”和判断依据，点击“保存当前材料点/未知”。
3. 查看第1、2帧。如果确认同一处细节，在对应位置点击并保存，仍用P01。如果只能看到相似螺纹，选`similar_texture`；看不清选`unknown`。这两种情况不要求点坐标。
4. 三帧能可靠对应时再向后扩展。某点只标2或3帧也有效，不需要追满21帧；消失后不要凭轨迹补点。
5. 同一案例内的新材料点换成P02、P03。同ID只表示人的对应主张，程序不会自动当成已确认真值。

误差半径是原始图像中的像素，不是放大后的屏幕像素。无法给出合理范围时填`unknown`。重标同一复核人、同一案例、同一帧、同一点ID会替换其旧记录；“删除当前点本帧标记”也只针对这组信息。

| 选项 | 何时使用 |
| --- | --- |
| `visible` | 能确认该材料细节可见，必须点击坐标 |
| `unknown` | 无法判断是否是同一处材料，不填猜测坐标 |
| `not_visible` | 确认该材料点当前不可见 |
| `similar_texture` | 看到了相似周期纹理，但不能确认材料身份 |
| `unique_texture` | 身份依据是可辨认的独特纹理组合 |
| `repeated_texture` | 依据主要为重复纹理，需要进一步核验 |
| `geometry_only`或`inferred` | 仅几何或经验推测，不当作精确材料真值 |

## 独立记录新层开始区间

`t1`是入卷位置的新绳真正开始爬到旧层上的时刻。侧缘稍后出现凸起、排线臂动作、工人敲击或按钮操作都可能提供线索，但不自动等于t1。

1. 选择“完整录像t1独立复核”案例，从干净录像自行寻找可辨变化，不参照算法结果或此前猜测的秒数。
2. 暂停到最后一帧能明确确认仍在旧层的画面，按“当前帧=最后明确旧层”。
3. 找到首次能明确确认新绳已爬到旧层上的画面，按“当前帧=首次明确新层”。两者构成一个区间，不强行给出单一小数秒时间点。
4. 点击“框选观察区域”，在原图证据区域的两个对角各点击一次。状态行显示已选的旧、新复核帧序号。
5. 真正入卷处直接爬层选`actual_entry`和`direct_climb`。如果只在侧缘稍后看见凸起，选`delayed_view`和`later_side_protrusion`；工人操作选`operator_button_or_hammer`。后两类只保留观察线索。
6. 接收时间与真实曝光时间的偏差目前未独立测定，时钟不确定度保持`unknown`，不要填0。需要解释的遮挡、观察方位、犹豫原因写进“说明”。
7. 点击“保存t1复核/未知”。始终看不清时清空区间、选择`unknown`并说明原因，同样可以保存。

`reviewed`仅表示该复核人已经检查过，不表示工业验收通过。工具会保留`independent_t1_confirmed=false`，待独立核验后由评估流程处理。历史上已经撤回的时间不能因记忆再次当成真值。

## 保存与多人复核

每次按保存按钮都会写入本包的[annotations.json](D:/precise_arrangement/vision_geometry_lab/outputs/v27_material_observability/v27_20261006_002/blind_review/annotations.json)。关闭前确认已按保存；仅在画面上点击还不算保存。标签只用于评估，不进入算法推理。

本工具会显示案例里已经保存的人工点，方便同一人续标。因此，第二位复核人不能直接在已经包含第一位标签的包中做“独立”复核。请让负责人准备新的包副本，保留相同`manifest.json`和`clean`图像，并提供空的`annotations.json`；两位复核人分别保存自己的文件，交付时注明姓名，不手工覆盖或合并对方的文件。空标签文件仍需包含`schema`、`material`、`t1`和`independent_confirmation_required`字段，不能删除文件代替初始化。

该包只对算法输出进行了盲化。看过历史录像的复核人可能认出场景，所以不称“完全双盲”。如果认出了旧时间或看过算法结果，请在说明中记录；不要为追求一致而修改自己的直接观察。

## 完成到什么程度即可反馈

第一轮只需要少量可确认的三帧材料对应，和一个有直接图像证据的t1区间。若四个材料案例都无法可靠对应，或者完整录像里只能看到延迟凸起，这也是有价值的结果：它说明下一步应改善可观察信息或独立参考，而不是继续猜标签。

将保存的标签文件反馈给项目负责人即可。无需操作相机、光源、排线臂或伺服，也不要为了标注到设备运行区域贴标记。
