## 先回答六个问题

1. **已完成训练、全搜索区域推理、有限路径连接和独立部分参考评分；尚未可靠识别完整目标弧段。** 路径确实越过自由段继续搜索，并非在首次接近卷面时主动结束。但网络仍会同时响应邻圈、股纹及设备结构，连接路径存在偏离、分支和错误的提前边缘到达。
2. **自由段后的延伸已实际发生，贴面身份未得到充分验证。** 已知入口8评价图均有候选，候选总长约1668–2520原图像素；其中5图被算法暂选、3图拒识。扣除120px输入入口后，5条暂选路径又搜索1548–1788px，其中1104–1692px落在共同场景的后段/近边缘视觉区域；自动分支4条暂选路径相应为1500–1968px、1128–1644px。这些是生成的几何长度，不能称为正确识别长度。独立部分参考中，已知入口的后段视觉区域5px覆盖仅23.42%，近边缘15.74%。部分“后段”在投影上仍可能悬空，不能当作已确认物理接触。详见[延伸长度及拒识分母](evaluation/extension_lengths.json)。
3. **确有偏离和未解决分支。** 左视角`113745/f00550`保留2条候选并拒识，中后段有折跃；右视角`113305/f00500`虽被选出并碰到观察边缘，末段仍明显偏离独立白色参考。C04/C05长距离弱支持后拒识。未把暗区都解释为遮挡。详见固定局部图与逐图评价JSON。
4. **CONDITIONAL与AUTO严格分开。** CONDITIONAL输入已有自由入口前120px；AUTO使用同图冻结V28自动入口前120px，5/8可用、3/8失败。AUTO失败全NaN，没有换用已知入口。自动分支4/8暂选，4/8拒识。不是任意新图自动入口流水线的验证。
5. **输入、局部支持、歧义分别输出。** `entry_condition`是已给提示，不计识别；`visible_supported`是网络及原图局部剖面支持，不等于独立确认同一目标；`ambiguous`保留低支持/竞争分支。已知入口5条暂选路径各有204–396px标为歧义，自动分支4条暂选路径为36–384px；没有独立真实遮挡证据，本轮`inferred`长度为0。独立评分只认可已有可信中心参考内的几何匹配，未标注范围保持未知。
6. **下一步最值得补的是目标身份监督。** 先在少量代表图补“竞争接续之后的正确目标锚点＋同一目标的远侧末端锚点”，并标一条紧邻错误旧圈作为负例，形成可核验的局部接续标注；不需标完整卷面。评价图新增参考只能用于冻结后的评分，不能回流调参。本轮证据不支持优先再加训练步数或更换暗区增强。

## 输入、入口及目标边缘

原图4096×3000，固定图像搜索框`[0,1050,4096,3000]`，不依赖标签末端。模型使用975×2048完整区域，即2倍等比下采样；不是只有入口的小patch。灰度float保留真实0，搜索框全部为输入有效域，不用`I>0`重建掩模，也不沿用排除活动绳的effective mask。每个入口和上下文已通过叠图检查。全ROI按实际mean/std标准化，std下限0.08；补边为标准化0。框外输出NaN，processed副本才置0。没有滑窗拼接接缝。

本轮固定原灰度，不同时调整LCN、背景相减或增益。短入口σ=4原图px，前120px之外的free_seed与目标路径不作为网络提示。U-Net内部把种子加权全局图像描述、种子质心/二阶矩和相对位置送到瓶颈，远端不依赖一个已经离开种子的局部patch。输入点可能位于视野内部；本轮路径范围从该提示起点向前，不把图像边框到提示点的未评分自由段算作已完整验收。

终止边缘候选来自原图`arc_detector`实际观察到的灰绳/黄法兰界面，取沿入口前进方向的远侧翼；缺失弧不拟合外推补满。真实原图边框、固定搜索框和该观察界面分别记录。进入界面24px邻域只记`observed_edge_candidate_reached_identity_unconfirmed`，不记完整成功。接近位置和四阶段是视觉位置代理；未知接近点不臆造物理接触。

## 监督和网络

单中心响应头，小型U-Net通道8/16/32/64、135897参数，灰度+入口两输入通道。没有旧单输入模型微调；本轮从保存的确定性初始化训练，过拟合后重置到同一初始化再跑基线。输出是0–1响应强度。

可信中心线生成σ=3原图px高斯；核宽仅定义定位响应，不是真实绳宽。只在可信两侧围成的局部区域与窄外侧负带监督，其他ignore。没有把固定绳径膨胀成真实主体mask，也没有把未知尾段改负类。训练搜索图约99.43%像素没有身份监督，这解释了未监督邻圈/工具上的响应为何不能由当前损失自动排除。
