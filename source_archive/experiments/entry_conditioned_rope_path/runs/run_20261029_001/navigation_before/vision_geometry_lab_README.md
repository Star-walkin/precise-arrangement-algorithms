## 先运行

双击本目录的 **启动独立弧线与活动绳实验.cmd**。它复用 `vision_prototype/.venv` 中已安装的 OpenCV、NumPy、Pillow，不要求重新安装环境。

1. 点击“打开图片／视频”，选择原始 BMP、JPG、PNG 或 AVI、MP4 文件。
2. 首帧自动检测。图片无须运动，左右相机都可用，不需要输入相机编号。
3. Ctrl＋滚轮放大、右键按住拖动；F2 显示／隐藏标注，Ctrl＋0 恢复适应窗口。
4. 视频可以跳转秒数、前后逐帧、逐帧分析播放。播放速度取决于运算，不是生产实时速度；每帧独立检测，没有拿上一帧数值伪装本帧结果。
5. “保存本帧结果”会在 `outputs/manual/时间戳/` 保存原图、简洁叠加图、含屏蔽带和原始点的诊断图、测量 JSON。不会覆盖原素材。写入失败时仅留下 `.incomplete` 目录并报告错误，不声称保存完成。
6. 默认显示有图像支持的局部边界、自由活动绳和新入卷轨迹候选。完整椭圆是单独的可选研究图层：拟合失败不再让有效局部边界消失。需要检查时，勾选“原始边界点”“绳屏蔽带”。“屏蔽余量px”是在估计半绳宽及定位裕量之外额外扩展的原图像素，默认 8。修改后旧结果失效，需重新检测；不应仅为得到想要的相切结论反复调整。

### 标注含义

| 显示 | 含义 |
|---|---|
| 绿色分段曲线 | 经邻域颜色支持筛选、局部平滑的内侧交界；缺口不连接，不依赖完整椭圆成功；仍非逐点真值 |
| 淡蓝色虚线（可选） | 完整椭圆的建模弧段，含遮挡区域外推；通过稳定性检查才显示，不是实测边界 |
| 白色点（可选） | 本帧原始颜色过渡候选，包括最终被稳健拟合剔除的离群点 |
| 蓝灰色平行虚线（可选） | 不参与弧线像素测量的活动绳屏蔽条带 |
| 橙色直线 | 估计活动绳中心线及其延长线，不是整段都实际可见 |
| 青色粗线 | 本次用于拟合的可见绳段范围；端点不是物理绳端点或切点 |

| 紫色圈 | 拟合椭圆上切线平行于活动绳的模型位置；即使直线与椭圆不相切也可以存在，不代表真实接触点或新层起点 |
| 蓝色圈 | 活动绳中心线与当前建模弧段内的交点；交点不等于切点 |

角度是图像坐标下无向直线方向，模 180°；图像 x 向右、y 向下。偏移量满足 `nx*x + ny*y = rho`，单位是原图像素。它们不是运动方向或毫米。

## 方法

### 弧形内边界

先独立检测活动绳 → 以中心线及延长线构造平行屏蔽条带 → 黄色区域定位和内凹结构定位 → 只在屏蔽区外原始分辨率颜色过渡中采样 → 二维邻域确认法兰颜色支持、剔除弱反射/侧轮廓候选 → 分段局部平滑；另行尝试稳健椭圆拟合与正交距离精修，并检查观测跨度、退化程度和删去局部弧段后的模型变化。

屏蔽是“不使用这些像素作为边界测量证据”，不是把图片涂黑制造新边缘。粗定位仍读取完整黄色区域；精修剖面若与屏蔽带相交，不能读取该带像素作为精测依据。可以在安全区域重新找有真实颜色支持的候选点。

理想平面圆的透视成像可用椭圆描述，因此这里选择单一椭圆模型，而不是任意高阶多项式。它是现场轮廓的近似：钢丝绳表面起伏、黄色包覆、镜头畸变均可能让真实轮廓偏离椭圆。拟合会让线平滑，但不能保证真实边界就是曲线中心。低残差只代表与选中像素一致，不等于亚像素绝对精度。

只绘制观测点跨度覆盖的部分弧，不发明完整底部轮廓。短弧、明显退化或扰动敏感性过大时拒绝完整椭圆，但保留可靠局部绿色边界。椭圆建模统一用淡蓝虚线，模型不确定性单独显示。黄色仍是现场先验，不同颜色法兰、严重掉漆、黄色遮挡物或极暗场景不保证可用。

### 活动绳

多方向直线候选 → 可选 SAM2／提示点／搜索框引导 → 独立亮条和法兰邻域证据筛选 → 优先双侧黄色背景上的自由绳消色差轮廓，否则使用孤立亮条 → 原图法线剖面测量 → 鲁棒正交直线拟合。

精修限于已找到的自由绳支撑段，避免卷绕纹理把直线拉偏。输出参考光学宽度、沿绳观测变化范围、参考位置和直线角度/位置敏感性；这些范围是经验诊断量，不是统计置信区间，不是物理直径。接触处的宽度并未因此得到直接测量。

不需要历史运动、不使用固定左右相机角度、不借“应该相切”强制选直线，不要求识别真实起终点。自动候选仍有保守的最小长度、宽度、对比度和场景约束，不能保证所有绳径、所有角度或完全遮挡下都检出。自由绳显著弯曲时，单一直线本身也不再合适。

### 新入卷绳表面轨迹（实验候选）

自由绳提供起始方向与位置，在卷面建立定向搜索条带，提取脊线特征，以连续性和弯曲约束保留多个路径候选。边界不参与路径打分以“吸引”路径重合，仅用于方向辅助与事后几何比较；它不能作为贴边真值。

此次人工标注暴露出：全自动亮脊追踪会偏到邻绳及股丝反光，并在暗处提前终止。人工提示分支增加局部对比度归一化、亮/暗双向候选及沿提示方向的搜索走廊。它仍从干净原图寻找特征，不读取红点像素，也不把提示连线当作观测。自动分支尚未可靠解决“哪一条曲线才是刚卷入的整根绳”的身份问题。

紫色候选目前可能只是绳股亮纹、阴影或绳体边界，不应直接视为整根绳的中心线。靠法兰一侧的绳体边缘与局部法兰边界，比“无限延长直线相切”更贴合问题；但接触附近实体宽度、遮挡与深度仍未解算。当前不把两曲线最近距离转成物理接触判断。

### 相切研究量（自由直线与可选椭圆）

分别计算中心线与完整椭圆、与当前建模弧段的交点数。完整椭圆可以有 2/1/0 个实交点；可见弧只有 1 个交点不代表相切，另一个交点可能不在可见弧内。相切位置限定在有观测跨度支持的弧段，不能使用隐藏对侧的支持点触发候选。

“两个交点足够近”不采用固定几像素：先从直线位置/角度变化、候选附近椭圆敏感性、拟合残差形成有上限的诊断容差，再求向椭圆内平移该距离后的交点间距，作为随曲率和尺度变化的交点合并参考。接近相切时弦长对法向误差非常敏感，因此同时报告法向间隙，不能只用弦长。

角度误差从自由绳拟合参考点传播到候选位置；不确定性过大不能因为容差变大就更容易判近切。光学绳边判定还检查宽度变化范围；不把自由段宽度等同接触处真实宽度。所有容差目前都是实验设置，不是工业验收阈值。

“中心线近切候选”或“光学绳边近切候选”只表示图像几何证据。任何结果都固定输出 `last_turn_confirmed=false`、`physical_contact_confirmed=false`、`new_layer_confirmed=false`、`force_command=null`。没有使用上一帧来强行维持候选，也没有使用人工给定时间调整检测结果。

## 为什么暂时不输出“新层已开始”

- 旧层最后一圈贴边，也可能满足图像相切；必须验证它与新层开始能否区分。
- 透视投影下，画面相切不能反推出两个不在同一深度的实体真实接触。
- 活动绳可能恰好遮住交界线；此时不能把绳自身边缘当成法兰边界再证明“相切”。
- 钢丝绳反光可能偏在一侧，半峰高亮带并非可靠物理直径，当前没有镜头畸变校正或毫米标定。

先验收弧线与直线定位，再使用清晰换向序列研究时序。此阶段不把根数、转速、编码器或伺服逻辑加入检测链。

## 方法资料

- [OpenCV LineSegmentDetector](https://docs.opencv.org/4.x/db/d73/classcv_1_1LineSegmentDetector.html)：直线候选检测；不代表能理解哪根是活动绳。
- [OpenCV 形状分析与拟合](https://docs.opencv.org/4.x/d3/dc0/group__imgproc__shape.html)：几何拟合方法参考；本实验的精修与鲁棒拟合代码独立实现。
- [OpenCV 相机模型与畸变](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)：理解透视投影与镜头畸变的区别；本实验未假装已经完成现场去畸变。
- [Meta SAM2 官方项目](https://github.com/facebookresearch/sam2)：提示式图像／视频分割；这里使用已有权重提供候选区域，不将掩膜当成亚像素真值。
- [OpenCV 脊线滤波](https://docs.opencv.org/4.13.0/d4/d36/classcv_1_1ximgproc_1_1RidgeDetectionFilter.html)：Hessian 曲线特征方法参考。特征提取不负责区分相邻绳身份；当前用自编定向特征与多路径搜索，未增加 ximgproc 依赖。
- [IPOL RORPO](https://www.ipol.im/pub/art/2017/207/) 与 [ELSDc 作者代码](https://github.com/viorik/ELSDc)：参考曲线连续性和弧段验证思路；未下载、复制或集成这些实现。
