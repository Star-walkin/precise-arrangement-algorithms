# 本轮用户要求：冻结A/B热图的线段提取与短缺口连接

不训练或微调任何神经网络，不增加关系模块，不开展N/G监督消融。实际实现新的后处理、运行对照并交付结果。

## 目标与范围

固定现有热图和入口，先提取方向连续的线段，再连接短缺口，验证能否比现有逐步搜索更准确恢复活动绳路径。最终目标包括从入口、明显斜向段、与卷面重叠过渡、继续沿正确目标至可见边缘；不能只展示斜向段就称完整识别。

P0为现有连接器，原配置保持；P1为中心线段提取＋方向约束短缺口连接＋片段路径选择。分别在冻结A/B热图运行，形成A/P0、A/P1、B/P0、B/P1。优先使用run_20261030_002共同750步输出，核实manifest/元数据。

重点样例dual_20260923_101517__pair0075__right，入口1/2、2/2分别处理，不事后挑好者。查清原图、checkpoint、入口来源与坐标映射，不把pair编号转换成帧号。若是训练来源，只作开发展示，不混入独立评价。正式沿用固定8评价图及来源划分。

## 固定输入

直接读取原始灰度、A/B原始response.npy、对应入口短段/前进方向、有效域/缩放/映射和独立评价参考。不得从彩色JPEG反推浮点，不把缩图像素当原图px。优先复用已有输出，缺失才用已核验冻结checkpoint和同入口补一次前向并记录，不调整输入。原响应不变，滤波/脊线/二值候选/补线另存派生数据。区分域外NaN、padding、原图真实0；不以I>0构造有效域，不用排除自由绳的旧卷面mask。不得用后段GT裁剪搜索走廊或把真实末端当额外输入。

## 提取什么

输出为窄中心响应，优先中心高响应脊线。在少量清晰自由段和过渡处看同坐标灰度/浮点热图法向剖面、中心候选及局部方向，确认峰和两侧低带关系。不追踪暗带、不整图取反。低带仅辅助提出中心，不是真边界/物理宽。中心弱但两侧成对持续时只作辅助候选，回原灰度检查。不得为连续性加宽中心/修改热图，不产生声称真实绳宽的mask。

## P1实现

1. 浮点热图局部方向、Hessian/线响应、沿法向峰值/NMS。仅现有numpy/OpenCV，不装包。要求沿线连续且横向峰，避免大块高响应背景。轻度去噪尺度按中心响应带宽，不是整绳径。模型尺度提取可回原图精修，阈值/段长/gap/评价距离统一原图px并记录换算。
2. 高低阈值与方向一致组成有序片段；高响应为可靠起点，弱位置只有方向相容且热图或原图支持才延续，孤立弱点不因低阈值就加入。无证据缺口留桥接，不伪称检测。骨架仅在线候选上，不对高亮大块直接骨架。每段记录有序原图坐标、端点切向、长度/曲率、中心响应/对比统计、原图支持、可用响应带宽/光学宽度、是否近计算边。交叉点不自动物理连接，保留沿原方向延续。
3. 起始段由已有入口位置/方向选相容者，不选全图最亮最长；手持杆、导件、支架可能有斜线。同图多入口各跑，种子已给部分不计新增识别。
4. 端点桥接至少检查gap长、两端切向、横偏、局部带宽/原图结构、缺口图像证据、竞争。优先短一致gap，可短直线或受约束曲线。不能大核膨胀粘邻圈；方向形态学限制横向范围。允许路径转弯，不固定斜率外推整绳。单gap及总补线量设上限，不无限跨未知去到边缘。每边记录端点、长、方向差、横偏、图像支持、分数及接受/拒绝理由。
5. 有向片段图/有界搜索，优先短gap、方向与图像/热图支持，惩罚横跳/长gap/无支持。不能重复绕同片段；合理竞争≤3，允许拒绝/早停。不强拼完整线。可轻平滑已选线但不能跨长未知/改归属；保留平滑前坐标。

## 参数预算

P0步长/beam/评分/停止不变。P1几何/桥上限/预算在正式评价前冻结，对AB一致。如需分别校准热图阈值，原则同一、只在训练/校准图、每模型固定一套并记录，不逐评价图调参，不逐图minmax。少量训练图确定一套主配置，不大规模搜索/反复看eval调至成功。限制片段数、每端点连接数、搜索扩展和单图时间，超限记录不无限重试。同一热图片段缓存，多入口复用。记录P0/P1真实耗时，状态表示不同，不能因beam相同称计算公平等量。

## 状态及显示

heatmap_supported、image_supported（弱热图但原图支持）、bridged（依端点跨gap）、ambiguous（不足/竞争）分开。状态只说证据，不确认身份；bridge不能叫真实检测或遮挡恢复。支持实线，bridge虚线，歧义/竞争不同色/线型，入口/方向单独。原灰度AB显示一致，派生ridge单独命名色标，不能覆盖原始输出。

## 公平评价

旧训练/评价来源不变，不访保留，不把近帧/多入口算独立。8eval的CONDITIONAL/AUTO分开，AUTO无入口失败保留，不known救auto、不事后挑模式。GT只评分，不提线/桥接/选末端。在相同参考范围比较四组合。至少：四阶段部分参考覆盖与距离；连续漏段；可靠范围首次偏离/错接；暂选/拒识/入口失败数量；支持/bridge长度及比例；总候选/竞争路径数/实际耗时。分别计只支持段的覆盖与含bridge的完整输出几何覆盖，不能将桥近GT当检测证据。拒识留主分母；路径变长平滑连通本身不成功。无完整末端GT完整成功率仍undefined；区分原图边、计算边、观察卷面界面。

## 交付及结论

独立目录，旧模型/响应/结果不变。交付400图里有绳图片的原图＋热图A＋热图B＋原图上活动绳识别掩膜图四联拼图，以及简明报告。中心路径没有可靠宽度时第四栏必须明确为中心线示意覆盖，而非真实绳体宽mask；支持/bridge/歧义可分。

最终先回答：明显斜向段是否主要短gap恢复；过渡后段是否保身份；相对P0改善来自提段还是桥；有无线完整却错邻圈；剩余是短断点、正确段缺失或竞争难选。若简单方案稳定可保留；若候选齐但选错，指出关系模块具体要处理的位置，本轮不训练网络。完成标准是实际运行及核验正确性，不只连续曲线。
