# 原图几何追踪与相对卷面方向 G0/G1：冻结协议

冻结日期：2026-11-03（北京时间）。方法标识 `IR-GEOM-G1.0.0`。本实验离线，不训练网络，不连接设备。

## 输入和数据用途

- 主图库严格使用 `inputs.json` 的 292 行顺序、原图 SHA-256 和固定 E1 两点入口；这是 D1 `final_292_index.json` 与 `protocol.json` 按 source ID 联接得到的 292 张唯一开放开发源图。任何 E1 缺失仍保留失败记录与结果图。其他入口不替代 E1。
- 只使用 `inputs.json` 中七个训练/开发来源组的七张事先按组中位序选择的图做开发检查。`pilot_001` 和 `pilot_002` 的误接与背景方向域问题分别记录于 `revision_pilot002.md`、`revision_pilot003.md`；`pilot_003` 是冻结前最后开发运行。
- 固定历史 8 张、3 来源组、AUTO 与 CONDITIONAL 分开评价；AUTO 旧入口失败仍留 8 张分母。`evaluation_inputs.json` 只含原图和入口元数据，目标可信参考只能在全部 G0/G1 预测先保存并哈希后加载。历史评价图已经开放，非新盲测；292 主图库不构成 292 张独立测试。
- 9 月 25 日及其他明确保留集不读取图像或标签。本轮不读取 S1 标签，亦不使用 A/B/D 网络热值或 SAM2/ONNX 卷面掩码作候选、评分、停止或方向域。

## 算法与对照

- 两组共同使用原图灰度、同一固定搜索框 `[0,1050,4096,3000]`、同一入口宽度模板、双侧法向剖面、路径连续性、几何响应、候选生成、beam 预算、有限无支持距离及停止规则。原图灰度 0 是有效值；只将未计算边框区域标无效。`geometry_core.py` 不导入神经网络模块。
- G0 无方向加分；G1 只在原图几何支持已通过、周围两侧下方大连通密集纹理卷面内核的无向双角方向可靠时给予每步最多 0.08 的软加分。方向未知或近平行时加分为 0。方向域是原图几何代理，不是人工确认的卷面语义真值。
- `config.json` 冻结所有数值参数和固定显示映射；全量主图库固定为 G1。G0 单独保存供对照，不按图挑较好版本。热力图是路径选择之前计算的原图结构张量响应，不按选中路径清背景，不作逐图 min-max。
- 最多保留三个不同候选；无法区分时拒识。输入 E1 段不算新识别长度。受支持段、有限无支持补接段、图像边界和搜索框边界分开记录。所有路径仅为图像几何候选，不确认同根材料、真实接触或物理换层。

## 固定评价和停止口径

- 使用现有可信部分中心线、质量排除区、原图坐标与 5 px 容差；评分排除已给的入口部分。报告全参考、后段及近边区域覆盖，以及仅 `image_supported` 段的覆盖；未知尾段不作正负例。首个持续 60 px 偏离仅是后验可信参考的几何代理。AUTO/CONDITIONAL 分开汇总。
- 只有 G1 的受支持后段和近边覆盖在至少两个独立来源组相对 G0 净增，且未引入目视可核验的新增错接，才建议继续投入方向辅助。否则停止该方向分支并保留失败案例。由于没有完整末端身份参考，不计算整根正确率。
- 固定全量成本：原图逐张处理，2 个 CPU worker，单图搜索最多 305 步；单图异常如实记录并输出失败图。`final_292` 应恰好 292 张双栏 PNG，左侧 4096×3000 原彩像素不绘制，右侧同原图坐标的固定 0–1 TURBO 几何响应与 G1 选中候选。未计算区域中性灰。
